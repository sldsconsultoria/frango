Integração com Google Sheets

Depois de configurada, toda a operação do app (vendas, despesas, estoque, preços, usuários e config) é salva automaticamente nesta planilha do Google — não fica mais só no navegador. Requer publicar um pequeno script no Google Apps Script (gratuito) — veja o passo a passo abaixo. Os botões abaixo servem só para forçar uma sincronização manual, se precisar.

Como configurar (passo a passo)
  1. Crie uma planilha nova no Google Sheets (sheets.google.com).
  2. Vá em Extensões → Apps Script.
  3. Apague o código de exemplo e cole o conteúdo do arquivo google-sheets-sync.gs — baixar arquivo.
  4. Clique em Implantar → Nova implantação, tipo App da Web. Em "Quem pode acessar", selecione Qualquer pessoa.
  5. Copie a URL gerada (termina em /exec) e cole no campo acima.
  6. Clique em Salvar link e depois em Enviar dados agora.

Backup e restauração

Faça backup regularmente para não perder seus dados. O backup é salvo apenas neste navegador/dispositivo.
